# せーの指名

部屋番号(公開)とパスワード(部屋主が決める)で入る、指名マッチングのWebアプリです。
外部パッケージは使わず、Node.js 18以上だけで動きます。

## 遊び方

1. 部屋主が「部屋を作る」で部屋名とパスワードを決める(部屋番号は自動で決まります)
2. 参加者は部屋番号を開き、パスワード・お名前・性別を入れて入室する
3. 部屋主が「第1周を始める」を押すと、参加者に異性の名簿が出る。1人を選んで「この人に決める」
4. 部屋主が締め切ると、部屋主の画面で1件ずつ結果を発表できる(成立、他からの指名数、お互い以外の指名なし、など)
5. 「第N周を終了」を押すと参加者にも自分の結果が出る。成立した2人は次の周の名簿から消える
6. どちらかの性別がいなくなるまで繰り返す

## 2つのモード

部屋を作るときに選びます。

- **ダブルモード**: 参加者が2チームに分かれ、相手チームの名簿から1人を指名します。チーム名は部屋主が自由に付けられます(例: 男性/女性、先輩/後輩、A/B)。
- **シングルモード**: チームに分かれず、参加者全員の名簿から、自分以外の1人を指名します。コミュニティ内でペアを決めるときなどに使えます。

あとの流れ(周ごとの発表、成立した人を名簿から外す、部屋主メモ)は、どちらのモードも同じです。
シングルモードでは、残りが1人以下になった時点で自動的に終了します。

## 自分のパソコンで試す

```
node server.js
```

ブラウザで http://localhost:3000 を開きます。同じWi-Fiのスマホからは、パソコンのIPアドレスを使って開けます。

## インターネットに公開する(例: Render)

1. このフォルダをGitHubのリポジトリにアップロードする
2. Render(https://render.com)で「New Web Service」を作り、そのリポジトリを選ぶ
3. Build Commandは空欄、Start Commandは `node server.js`
4. 発行されたURLを参加者に伝える

注意点:

- 無料プランは一定時間アクセスがないと停止し、再起動時にデータが消えることがあります。当日のイベントだけなら問題ありませんが、直前に動作確認し、開催中はアクセスを保つようにしてください。
- 保存先を変えたいときは、環境変数 `DATA_DIR` にフォルダを指定します。
- 部屋は最後の操作から72時間で自動的に削除されます。

## 仕様メモ

- 部屋主は参加者にはなりません(全員の結果が見えるため)。
- ブラウザを閉じた参加者は、部屋番号・パスワード・登録した名前だけで入り直せます(性別は不要)。閉じる前の画面に戻り、選択済みの指名も残っています。同じ名前の参加者は想定していません。パスワードを知っている人は他人の名前でも入れるため、顔見知りの集まりで使ってください。
- 部屋主の画面には「部屋主メモ」が出ます。結果発表の間は常に表示され、成立したカップルが他から何人に指名されていたか、マッチなしの人が何人から指名されていたか、すれ違い(以前の周で指名していた人から、今回は逆に指名されている)、成立した2人の過去の指名がわかります。
- 部屋主メモは参加者には送られません。部屋主の端末を他の人に見せないようにしてください。
- 部屋主が端末を変えるときは、部屋主の設定に表示される復帰コードを使います。
- パスワードの試行は、同じ端末から10分に8回までです。
